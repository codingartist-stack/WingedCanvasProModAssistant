# Privacy Policy for Winged Canvas Pro Mod Assistant

**Last Updated: November 3, 2026**

The Winged Canvas Pro Mod Assistant extension values and respects your privacy. This policy outlines how your information is handled.

## 1. Information Collection and Storage

- **No Server Collection:** The Extension does not collect, track, aggregate, or upload any personal data, browsing history, or operational logs to external servers.
- **Local Storage Only:** Any inputs provided by the user (such as the Moderator Profile Name Configuration or local Timestamp Logs) are processed and retained strictly within the user's local web browser engine environment using `localStorage`.

## 2. Permissions Usage

- **ActiveTab & Host Matches:** The extension requests access matching `https://youtube.com*` solely to dynamically position the helper dashboard panel element over the broadcast view and link quick-action helper text buttons to the YouTube live chat feed.

## 3. Third-Party Sharing

- Because no data is ever read, transmitted, or recorded by the developer, no information is ever shared, rented, or sold to third-party entities.

## 4. Changes to This Policy

- Any updates to this extension will prioritize this absolute zero-data-collection infrastructure.
